Практические примеры и домашние задания к курсу лекций «Системное программирование».

Курс: https://slides.com/gerold103/decks/sysprog и https://slides.com/gerold103/decks/sysprog_eng

### Запуск тестов

#### Вручную

Папки с числовыми именами содержат домашние задания с тестами, если для задания их удалось написать. Задания можно собирать и запускать вручную в любой не-Windows системе. Альтернатива — запуск в Docker; рекомендуется использовать актуальный образ Ubuntu.

Помимо функциональной корректности проверяйте отсутствие утечек памяти через `utils/heap_help/`.

#### Локальные автотесты

Чтобы запустить тесты так же, как их запускает удалённая автоматическая система (например, VK All Cups), выполните в папке `sysprog/` команды из английского раздела выше. В `HW=N` замените N на номер домашнего задания.

`HW=N` задаёт проверяемое задание. N должен совпадать с именем каталога, в котором находится решение. Решения предполагается реализовывать в форке этого репозитория, в тех же папках, где находятся условия и шаблоны.

#### Удалённые автотесты

Команды локальных тестов немного отличаются от команд удалённой автоматической системы. Она выполняет команды из английского раздела «Remote auto-tests» в папке `sysprog/`.

Удалённая система берёт неизменённый репозиторий `sysprog/`, чтобы получить исходные тесты и Makefile. Затем она получает решение как архив, собирает его исходным Makefile соответствующего задания и запускает против исходных тестов. Номер задания определяется из `settings.json`; результат сохраняется в `output.json` и выводится в консоль.

Не изменяйте локальные тестовые файлы и Makefile. Иначе проверка решения разойдётся с проверкой в системе автотестов.
